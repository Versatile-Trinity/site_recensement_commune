Ce site a été créé pour permettre à tout citoyen de s'enregistrer dans la base de données communale n'importe où n'importe quand.
De plus le but de son existence est aussi de faciliter le recensement des habitants dans la division supérieure (commune) et les divisions inférieures (Fokontany).

Comment ça fonctionne ?

Vous pouvez vous enregistrer et également enregistrer vos proches. Il vous suffit de renseigner vos informations d'état civil de base ; un agent communal validera ensuite votre dossier.

Premier enregistrement ?

Si vous n'êtes pas encore recensé dans notre système, vous pouvez entamer les démarches directement ici.
