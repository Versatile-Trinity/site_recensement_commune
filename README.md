# site_recensement_commune
This is a web project. It is a site created to allow every people living in a specific area to register themselves inside a database specific to that area, thus facilitating the census of these people by the governement for example
I used the basics of web programming : HTML , CSS , and a little bit of JS. Also Symfony but not entirely, I used mostly PHP. As a database I used wampserver.
